# How to Run

To run the code, follow these steps:

1. Place the desired video file in the `video` folder located in the root directory of the repository.
2. Run the `main_YOLO` program.
3. Use your mouse to select the boundary points of the desired region of interest (ROI) in the video.
4. After selecting the boundary points, press `Enter` to start the model.

**Note:** Make sure the video is placed in the `video` folder before running the program.
